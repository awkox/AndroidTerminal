# 支持的 xterm 转义序列

本文档详细列举 AndroidTerminal 终端仿真器所支持的全部转义序列，按序列类型分类说明。

> 相关源码：
> - 序列解析：`AnsiEscapeParser.kt`
> - ESC/CSI 处理：`TerminalEmulator.kt`
> - OSC 处理：`OscHandler.kt`
> - DCS 处理：`DeviceControlHandler.kt`
> - 输入方向编码：`KeyHandler.kt`、`InputSequenceEncoder.kt`

记号约定：`ESC` = 0x1B，`CSI` = `ESC [`，`OSC` = `ESC ]`，`DCS` = `ESC P`，`ST` 为字符串终止符（`ESC \` 或 BEL）。

---

## 1. 控制字符

| 字符 | 十六进制 | 名称 | 行为 |
|------|---------|------|------|
| NUL | 0x00 | 空字符 | 忽略 |
| BEL | 0x07 | 响铃 | 触发 `onBell()`（当前默认无声音，可被通知拦截） |
| BS | 0x08 | 退格 | 光标左移一列；位于左边界且上一行有换行标记时回到上一行行尾 |
| HT | 0x09 | 水平制表 | 光标移到下一制表位 |
| LF / VT / FF | 0x0A / 0x0B / 0x0C | 换行 | 执行换行（光标下移，行尾触发滚动） |
| CR | 0x0D | 回车 | 光标移到左边界 |
| SO | 0x0E | Shift Out | 后续字符使用 G1 字符集（线绘字符） |
| SI | 0x0F | Shift In | 后续字符使用 G0 字符集 |
| CAN / SUB | 0x18 / 0x1A | 中断 | 序列解析中收到则终止序列并转发 DEL(0x7F) |
| ESC | 0x1B | 转义 | 开始转义序列 |

## 2. ESC 序列（两字符）

| 序列 | 名称 | 行为 |
|------|------|------|
| `ESC 6` | DECBI 反向索引 | 光标左移；已在左边界时整行右移一列 |
| `ESC 7` | DECSC 保存光标 | 保存光标位置、字符属性、颜色、线绘状态与 DEC 模式位 |
| `ESC 8` | DECRC 恢复光标 | 恢复由 DECSC 保存的状态（不含左右边距与反向视频） |
| `ESC 9` | DECFI 正向索引 | 光标右移；已在右边界时整行左移一列 |
| `ESC c` | RIS 完整复位 | 重置仿真器全部状态并清空回滚历史 |
| `ESC D` | IND 换行 | 光标下移（行尾触发滚动），列不变 |
| `ESC E` | NEL 下一行 | 光标移至左边界后换行 |
| `ESC F` | 光标移动 | 实现为将光标置于 0 行、下边界 - 1 列（与标准 xterm 的左下角定位存在差异） |
| `ESC H` | HTS 设置制表位 | 在当前列设置水平制表位 |
| `ESC M` | RI 反向换行 | 光标上移；已在上边界时向下滚动 |
| `ESC N` / `ESC 0` | SS2 | 忽略 |
| `ESC =` | DECKPAM | 小键盘进入应用模式 |
| `ESC >` | DECKPNM | 小键盘退出应用模式 |
| `ESC # 8` | DECALN | 屏幕对齐测试：整个屏幕填充 `E` |

### 字符集选择

| 序列 | 行为 |
|------|------|
| `ESC ( 0` | G0 选择 DEC 特殊图形字符集（线绘字符） |
| `ESC ( B` 等 | G0 选择 ASCII（`0` 之外均视为 ASCII） |
| `ESC ) 0` | G1 选择 DEC 特殊图形字符集 |
| `ESC ) B` 等 | G1 选择 ASCII |
| `ESC %` | 字符集选择（当前忽略） |

线绘字符映射详见[附录 A](#附录-a线绘字符集映射)。

## 3. CSI 标准序列

CSI 参数规则：最多 32 个参数，数值上限 9999；`;` 分隔参数、`:` 标记子参数；缺省参数为 -1（由各命令按需取默认值）。

### 3.1 光标移动

| 序列 | 名称 | 行为 |
|------|------|------|
| `CSI n A` | CUU 上移 | 光标上移 n 行（默认 1），受原点模式边界限制 |
| `CSI n B` | CUD 下移 | 光标下移 n 行（默认 1） |
| `CSI n C` | CUF 右移 | 光标右移 n 列（默认 1） |
| `CSI n D` | CUB 左移 | 光标左移 n 列（默认 1） |
| `CSI n E` | CNL 下一行 | 光标下移 n 行并到行首 |
| `CSI n F` | CPL 上一行 | 光标上移 n 行并到行首 |
| `CSI n G` | CHA 绝对列 | 光标移到第 n 列（1 起算） |
| `CSI r ; c H` / `CSI r ; c f` | CUP 光标定位 | 光标移到第 r 行第 c 列（受原点模式影响） |
| `CSI n I` | CHT 前向制表 | 光标前移 n 个制表位 |
| `CSI n Z` | CBT 反向制表 | 光标后移 n 个制表位 |
| `CSI n \`` | HPA 绝对列 | 同 CHA，按原点模式相对定位 |
| `CSI n a` | HPR 右移 | 光标右移 n 列 |
| `CSI n d` | VPA 绝对行 | 光标移到第 n 行（1 起算） |
| `CSI n e` | VPR 下移 | 光标下移 n 行（相对滚动区原点） |

### 3.2 编辑与擦除

| 序列 | 名称 | 行为 |
|------|------|------|
| `CSI n @` | ICH 插入字符 | 光标处插入 n 个空格，右侧内容右移 |
| `CSI n P` | DCH 删除字符 | 删除光标起 n 个字符，右侧内容左移 |
| `CSI n X` | ECH 擦除字符 | 将光标起 n 格替换为空格（不移动光标） |
| `CSI n L` | IL 插入行 | 光标行起插入 n 行 |
| `CSI n M` | DL 删除行 | 删除光标行起 n 行 |
| `CSI n S` | SU 上滚 | 滚动区内容上滚 n 行 |
| `CSI n T` | SD 下滚 | 滚动区内容下滚 n 行 |
| `CSI n b` | REP 重复字符 | 重复输出上一个可打印字符 n 次 |
| `CSI Ps J` | ED 擦除显示 | 0=光标到屏尾，1=屏首到光标，2=全屏，3=清空回滚历史 |
| `CSI Ps K` | EL 擦除行 | 0=光标到行尾，1=行首到光标，2=整行 |
| `CSI Ps g` | TBC 清除制表位 | 0=清除当前列，3=清除全部 |

### 3.3 模式与状态

| 序列 | 名称 | 行为 |
|------|------|------|
| `CSI 4 h` / `CSI 4 l` | SM/RM（IRM） | 设置/重置插入模式（其余模式位忽略） |
| `CSI r ; b r` | DECSTBM | 设置上下滚动边界（上下边距），光标归位 |
| `CSI s` | DECSC 保存光标 | 未启用 DECLRMM 时保存光标状态 |
| `CSI s`（DECLRMM 启用） | DECSLRM | 设置左右边距，光标归位 |
| `CSI u` | DECRC 恢复光标 | 恢复保存的光标状态 |
| `CSI Ps n` | DSR 状态报告 | 5=状态报告（响应 `ESC [0n`），6=光标位置（响应 `ESC [r;cR`） |
| `CSI Ps c` | DA1 设备属性 | 参数为 0 时响应 `ESC [?64;1;2;6;9;15;18;21;22c` |

### 3.4 XTWINOPS 窗口操作（CSI Ps t）

| 参数 | 行为 |
|------|------|
| 11 | 报告窗口状态 → `ESC [1t` |
| 13 | 报告窗口位置 → `ESC [3;0;0t` |
| 14 | 报告窗口像素尺寸 → `ESC [4;h;wt` |
| 16 | 报告字符区域像素尺寸 → `ESC [6;h;wt` |
| 18 / 19 | 报告精确字符尺寸 → `ESC [9;rows;colst` |
| 20 | 报告图标标签 → `ESC ]LIconLabel ESC \` |
| 21 | 报告窗口标题 → `ESC ]l ESC \` |
| 22 | XTWTITLE 标题入栈（栈深上限 20） |
| 23 | XTWTITLE 标题出栈 |

## 5. DEC 私有模式（CSI ? ...）

### 5.1 DECSET / DECRST（CSI ? Ps h / l）

| 模式 | 名称 | 说明 |
|------|------|------|
| 1 | DECCKM | 光标键应用模式（方向键发送 `ESC O` 前缀序列） |
| 3 | DECCOLM | 132 列模式（简化处理：重置边距、清屏、光标归位） |
| 5 | DECSCNM | 反向视频 |
| 6 | DECOM | 原点模式（光标定位以滚动区为原点） |
| 7 | DECAWM | 自动换行（宽字符与行尾自动折行，行尾标记换行点） |
| 25 | DECTCEM | 光标可见 |
| 47 | 备用屏 | 切换到备用屏幕缓冲区 |
| 66 | DECNKM | 小键盘应用模式 |
| 69 | DECLRMM | 左右边距模式 |
| 1000 | 鼠标跟踪 | 按下/释放事件上报（X10 编码） |
| 1002 | 鼠标跟踪 | 按钮事件上报（含拖拽移动，与 1000 互斥） |
| 1004 | 焦点事件 | 焦点变化上报（`ESC [I` / `ESC [O`） |
| 1006 | SGR 鼠标 | 鼠标上报改用 SGR 编码（`CSI <b;c;rM/m`） |
| 1047 | 备用屏 | 切换备用屏并保存/恢复光标 |
| 1048 | 光标 | 设置时保存光标，重置时恢复光标 |
| 1049 | 备用屏 | 备用屏 + 清屏 + 保存/恢复光标 |
| 2004 | 括号粘贴 | 粘贴文本包裹 `ESC [200~` / `ESC [201~` |

### 5.2 其他 DEC 私有序列

| 序列 | 名称 | 行为 |
|------|------|------|
| `CSI ? Ps J` | DECSED 选择性擦除 | 同 ED，但跳过受保护字符（0/1/2 模式） |
| `CSI ? Ps K` | DECSEL 选择性擦除行 | 同 EL，但跳过受保护字符（0/1/2 模式） |
| `CSI ? 6 n` | DECXCPR 光标位置报告 | 响应 `ESC [?r;c;1R` |
| `CSI ? Ps s` | 保存 DEC 模式 | 保存当前 DECSET 模式位集合 |
| `CSI ? Ps r` | 恢复 DEC 模式 | 按保存的模式位恢复 |
| `CSI ? Ps $ p` | DECRQM 模式查询 | 响应 `ESC [?Ps;value$y`（1=已设置，2=未设置，0=未知） |

## 6. 其他 CSI 前缀序列

| 序列 | 名称 | 行为 |
|------|------|------|
| `CSI > c` | DA2 设备属性 | 响应 `ESC [>41;320;0c`（标识为 xterm 41） |
| `CSI Ps SP q` | DECSCUSR 光标样式 | 0–2=块状，3–4=下划线，5–6=竖线 |
| `CSI " Ps q` | DECSCA 字符保护 | 0/2=取消保护属性，1=启用保护属性 |
| `CSI ' Ps }` | DECIC 插入列 | 光标处插入 n 列 |
| `CSI ' Ps ~` | DECDC 删除列 | 删除光标起 n 列 |
| `CSI ! p` | DECSTR 软复位 | 复位仿真器状态（不清回滚） |
| `CSI * Ps x` | DECSACE 属性修改范围 | 0/1=行范围，2=矩形范围 |
| `CSI Ps ; Ps ; ... $ v` | DECCRA 复制矩形区域 | 8 个参数指定源矩形与目标位置 |
| `CSI ... $ {` | DECSERA 选择性矩形擦除 | 擦除矩形区域，保留字符视觉属性，跳过受保护字符 |
| `CSI ... $ z` | DECERA 矩形擦除 | 擦除矩形区域 |
| `CSI fill ; ... $ x` | DECFRA 矩形填充 | 以指定字符填充矩形区域 |
| `CSI ... $ r` | DECCARA 矩形属性修改 | 批量设置/取消矩形内字符属性（1/4/5/7/22/24/25/27） |
| `CSI ... $ t` | DECRARA 矩形属性反转 | 与 DECCARA 相同参数，但反转设置/取消语义 |

## 7. OSC 序列（ESC ] Ps ; Pt ST）

| 参数 | 名称 | 行为 |
|------|------|------|
| 0 / 1 / 2 | 设置图标名 / 窗口标题 | 更新终端会话标题 |
| 4 | 设置调色板 | `idx;colorSpec` 对，可多对串联；支持 `#RGB`、`#RRGGBB`、`rgb:r/g/b` 格式 |
| 10 / 11 / 12 | XTOSC 前景 / 背景 / 光标色 | `?` 时查询并以 `rgb:rrrr/gggg/bbbb` 响应；否则设置，可 `;` 串联多个从对应位置递增设置 |
| 52 | 剪贴板 | 写入剪贴板（Base64 编码内容，`c;` 前缀忽略） |
| 104 | 重置调色板 | 无参数时全部重置；否则按分号分隔的索引逐个重置 |
| 110 / 111 / 112 | 重置前景 / 背景 / 光标色 | 恢复对应颜色为默认值 |
| 119 | 忽略 | 显式忽略（清空回滚历史请求） |

## 8. DCS 序列（ESC P ... ST）

| 序列 | 名称 | 行为 |
|------|------|------|
| `DCS $q"p ST` | DA1 设备属性查询（VT100 格式） | 响应 `ESC P1$r64;1"p ESC \` |
| `DCS +q pt ST` | XTGETTCAP 终端能力查询 | 能力名十六进制编码、`;` 分隔批量查询。内置能力：`Co`/`colors` → `256`，`TN`/`name` → `xterm`；其余委托 termcap 按键表（见[附录 B](#附录-b-termcap-能力表)）。命中响应 `ESC P1+r pt=hex ESC \`，未命中响应 `ESC P0+r pt ESC \` |

## 10. 输入方向序列（终端 → shell）

模拟器主动发送的序列（鼠标、焦点、粘贴、按键）。

### 10.1 按键编码

| 按键 | 普通模式 | 应用模式 / 修饰 |
|------|----------|----------------|
| 上 / 下 / 右 / 左 | `ESC [A/B/C/D` | `ESC OA/B/C/D`（DECCKM） |
| Home / End | `ESC [H` / `ESC [F` | 同上 |
| F1–F4 | `ESC OP/OS` | 带修饰时 `ESC [1;mP` 等 |
| F5–F12 | `ESC [15~` … `ESC [24~` | 带修饰时 `ESC [n;m~` |
| Insert / Delete | `ESC [2~` / `ESC [3~` | 同上 |
| PageUp / PageDown | `ESC [5~` / `ESC [6~` | 同上 |
| Tab / Shift+Tab | `HT` | `ESC [Z` |
| 回车 / Alt+回车 | `CR` | `ESC CR` |
| 退格 | `DEL`（0x7F）；Ctrl+退格 = `^H` | Alt+退格前缀 `ESC` |
| Ctrl+Space | `NUL`（0x00） | — |
| Ctrl+字母 | 对应 ASCII 控制字符 | — |

修饰键编码规则：`base = 1`，Shift +1、Alt +2、Ctrl +4，写入 CSI 参数（如 `ESC [1;5C` = Ctrl+右方向键）。

### 10.2 鼠标编码

| 协议 | 格式 |
|------|------|
| X10（默认，1000/1002） | `ESC [M` + 3 字节（按钮 +32，列/行 +32，释放时按钮=3） |
| SGR（1006） | 按下 `ESC [<b;c;rM`，释放 `ESC [<b;c;rm` |

按钮码：0=左键，32=左键拖拽，64=滚轮上，65=滚轮下。移动事件仅在 1002 模式下上报。

### 10.3 焦点与粘贴

| 事件 | 序列 |
|------|------|
| 获得 / 失去焦点（1004 开启时） | `ESC [I` / `ESC [O` |
| 括号粘贴（2004 开启时） | `ESC [200~` + 文本 + `ESC [201~` |

粘贴文本过滤：剔除 ESC 与 C1 控制字符，换行统一为 `CR`（`CRLF` 合并）。

| `%i` / `#2` / `#4` / `*7` | Shift+右 / Shift+Home / Shift+左 / Shift+End | — | — |

## 附录 C：已知限制

- 明确忽略的序列：`ESC N`、`ESC 0`、`ESC %`、`OSC 119`（清空回滚）、`CSI < / =` 前缀
- SGR 6/21（快闪/双下划线）未实现；SGR 21 按未知代码处理
- 鼠标协议 1003（任意移动跟踪）与 1005（UTF-8 鼠标）未实现
- `ESC F` 的落点与标准 xterm 不一致（见[第 2 节](#2-esc-序列两字符)）
- OSC 52 仅支持写入剪贴板，不支持查询
